Personal use

The Daily Brief is a private tool developed and used by Henry Weil. This website provides information about the tool; it does not offer a public application, signup, subscription, or paid service.

Current scope

The current prototype reads explicitly authorized Gmail accounts for collection and completeness testing. Automated sending, message-label changes, and AI processing of connected mailbox content are not enabled. Additional features require separate authorization and updated disclosures where appropriate.

Briefing accuracy

The intended briefing is an aid to reviewing email. The original messages remain the source for obligations, dates, and source reporting. Generated summaries, when enabled, should be checked against those sources when decisions depend on their accuracy.

Control and changes

The owner may stop using the prototype and revoke its Google permissions at any time. Features and availability may change during development. Data handling is described in the privacy policy.
