A personal morning briefing.

The Daily Brief is a private tool developed and used by Henry Weil to organize his own email and produce a morning briefing. It is not offered as a public service.

Current status: weekday workflow scheduled for October 27, 2026. The owner has approved controlled local and Oracle-hosted briefing generation through OpenAI using the existing ChatGPT subscription, and self-addressed delivery tests. The owner has approved ongoing processing and personal self-delivery on weekdays. The replacement weekday workflow is scheduled on the owner’s Oracle server starting October 27, 2026. Mailbox cleanup is not enabled.

What the tool is designed to do

The intended briefing brings together important obligations, substantive newsletter reporting, other notifications, and optional subscription recommendations. Development is staged, with separate approval before features that send email or change message labels are enabled.

Google account access

The source collector requests gmail.readonly for the owner’s two accounts. A separate personal-account delivery credential requests gmail.readonly plus gmail.send for identity checks, delivery and reconciliation. Google’s send permission allows sending on the account’s behalf; the application code restricts this test’s sender and sole recipient to the owner’s personal address. The school account retains read-only access. No permission to delete or modify message labels is requested.

Public information, private inbox

This website contains application information only. Email contents, tokens, audit records, and briefing output are not hosted here. There is no public signup or inbox interface.
